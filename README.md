# 📊 Customer Shopping Behavior Analysis

## 📌 Overview

An end-to-end Data Analytics project focused on understanding customer purchasing patterns, shopping preferences, and sales trends.

The project uses Python for data cleaning and EDA, PostgreSQL for SQL-based analysis, and Power BI for interactive dashboard development. The objective is to generate meaningful business insights and actionable recommendations from customer shopping data.

## 🎯 Objectives

- Analyze customer purchasing behavior and preferences.
- Identify popular products and high-performing categories.
- Understand purchasing patterns across age groups.
- Evaluate discounts, subscriptions, and payment preferences.
- Generate actionable business recommendations.

## 📂 Dataset

The dataset contains customer demographics, purchase details, product categories, discounts, payment methods, ratings, and shopping preferences.

**Key columns:** Customer ID, Age, Gender, Item Purchased, Category, Purchase Amount, Location, Review Rating, Subscription Status, Discount Applied, Payment Method, and Frequency of Purchases.

## 🔄 Project Workflow

1. **Data Loading:** Imported and explored the dataset using Python.
2. **EDA:** Analyzed distributions, trends, and relationships between variables.
3. **Data Cleaning:** Handled missing values, duplicates, data types, and standardized column names.
4. **SQL Analysis:** Used aggregations, CASE WHEN, GROUP BY, and other SQL operations to answer business questions.
5. **Dashboard Development:** Created interactive Power BI visualizations and DAX measures.
6. **Reporting:** Prepared a project report and presentation highlighting findings and recommendations.

## ⚙️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/customer_behavior_analysis.git
```

**2. Install Python libraries**

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

**3. Run the analysis**

- Open the Jupyter Notebook.
- Execute the cells for EDA and data cleaning.
- Import the cleaned dataset into PostgreSQL.
- Execute the SQL analysis script.
- Open the Power BI `.pbix` file to explore the dashboard.
